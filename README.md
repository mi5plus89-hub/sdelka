# Этапы сделки — памятка покупателю

Интерактивная памятка для клиентов: 8 шагов сделки при покупке квартиры в новостройке.

**Условия:** эскроу-счёт в банке ДОМ.РФ, ипотека, материнский капитал в первоначальном взносе, паркинг или кладовая отдельным договором.

Александр Цыбульский, АН «Департамент недвижимости».

## Как устроено

Весь сайт — один файл `index.html`. Внутри уже есть стили, скрипты и иконки, внешних зависимостей нет. Правится в любом текстовом редакторе, работает без интернета.

## Что умеет страница

1. Список шагов читается как чеклист: у каждого пункта видна строка «От вас» — что требуется от клиента.
2. Панель «Сейчас» сама определяет первый невыполненный шаг и показывает текущую задачу.
3. Отметки о выполнении сохраняются в браузере клиента и переживают закрытие вкладки.
4. Светлая и тёмная темы, адаптация под телефон.
5. Печать в PDF: шаги раскрываются автоматически, кнопки скрываются.

## Что править чаще всего

- **Контакты** — блок `<section class="contact">` в конце файла: телефон, Telegram, MAX.
- **Тексты шагов** — блоки `<details class="step">`.
- **Строка «От вас»** — тег `<span class="ask">` внутри каждого шага; она же попадает в панель «Сейчас».

После правки файла обновите страницу в браузере, чтобы проверить результат.
